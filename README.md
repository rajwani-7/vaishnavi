# Raksha Bandhan Surprise

This is a no-build static site, ready for Netlify.

## Personalise it

- Change `sisterName` near the top of `script.js`.
- Replace `images/photo1.svg` through `photo4.svg` and `final-photo.svg` with your own images. If you use JPG files, also update their paths in `index.html`.
- Optionally add `music/rakhi-music.mp3`.

## Deploy on Netlify

Drag this entire folder into [Netlify Drop](https://app.netlify.com/drop), or import the folder's Git repository into Netlify. No build command is needed.
